# Brainstorm Worksheet — Bottom-Up to Pyramid

Use when the input is a messy list of ideas and the output must be a coherent story. This is Minto's inductive path.

---

## Step 1 — Dump

Write every idea, fact, claim, and half-thought. One per line. Don't edit. Don't judge.

```
-

- 
- 
- 
```

_(Aim for at least 15–20 items. If you have fewer than 10, the problem is you haven't dumped everything — go back.)_

---

## Step 2 — Cluster by same-kind

Group items that answer the same question or belong to the same class.

**Guiding question for each cluster:** "What do these items have in common — what class do they all belong to?"

If items resist clustering, they may not belong in this document. Move to a "parking lot".

```
Cluster A — <what these are all instances of>:

- 

Cluster B — <what these are all instances of>:
- 
- 
- 

Cluster C — <what these are all instances of>:
- 
- 
- 

Parking lot (does not belong):
- 
- 
```

---

## Step 3 — MECE each cluster

For each cluster:

- Any overlaps? → merge.
- Anything obvious missing? → add.
- Really two clusters pretending to be one? → split.

Rewrite the cleaned clusters:

```
Cluster A (cleaned):
- 
- 

Cluster B (cleaned):
- 
- 

Cluster C (cleaned):
- 
- 
```

---

## Step 4 — Abstract a summary sentence per cluster

For each cluster, write **a single sentence** that says something new about what the cluster collectively means. Not "these are three examples of X" — but "X is happening because of Y".

- **Cluster A summary:**
- **Cluster B summary:**
- **Cluster C summary:**

_(If your summary is just a category name — "Metrics" — you haven't abstracted. Push harder: what do the metrics collectively say?)_

---

## Step 5 — Group the summaries → apex

Now treat the three summary sentences as a new list. Do they themselves cluster? What single sentence summarizes all of them?

**Governing thought (apex):**

_(This is a claim, not a topic. "We should do X because Y." Not "an overview of the situation".)_

---

## Step 6 — Now write it top-down

Rebuild the story with the apex first:

- **SCQA introduction:**
  - S:
  - C:
  - Q:
  - A: _(= governing thought from step 5)_
- **Key line 1** = Cluster A summary → detail = cleaned Cluster A items
- **Key line 2** = Cluster B summary → detail = cleaned Cluster B items
- **Key line 3** = Cluster C summary → detail = cleaned Cluster C items

Pick an ordering (deductive / chronological / structural / degree) and re-order the key lines to match.

---

## Step 7 — Test the pyramid

- [ ] Reading top-down, does each level answer the question the level above raises?
- [ ] Do the key lines together fully support the apex?
- [ ] Would removing any single cluster break the argument? (If no, that cluster is decoration — cut it.)
- [ ] Is the governing thought a claim, not a topic?

If yes to all: you've turned the pile into a story. Deliver as a presentation, README, or memo per the matching workflow in SKILL.md.
